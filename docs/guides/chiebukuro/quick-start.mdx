## Onboard

```bash
chie init          # interactive wizard
chie preflight     # models, MCP, worker, Resonate, index
chie diagnostic    # CLI, QMD index, wiki store health
```

## Save knowledge

```bash
chie remember "Retry budget for mailbox sends is 2 with jitter; 3 wedges the daemon." --tags toron,mail
chie ingest https://example.com/spec
chie compile
```

`remember` writes an OKF wiki page immediately, deduplicated by content hash. `ingest` queues a raw source; `compile` extracts concepts (DSPy + lambda-RLM) into wiki pages. Compiled candidates pass the review queue (`chie review`, `chie promote`, `chie reject`); they never reach the live wiki by side door.

## Search it right

```bash
chie qmd search "retry budget" --agent
# L0: scan the gists (~350 chars each). A gist is a summary, not an answer.
chie get <path> --agent
# L1: fetch the top hit's full content before answering.
```

Always `--agent` on read commands: output over 2KB becomes a preview plus a file path instead of a context flood. Resolve paths with `chie get`/`chie sql` before any OS-level read.

## Recall what was decided

```bash
chie memory record "Chose MDX guides over MD: user asked for mdx"
chie memory recall "docs structure decision"
chie qmd search --memory "docs structure"   # both planes, labeled
```

## Deep questions

```bash
chie investigate "why does the dispatch guard match tags, not subjects" --agent
chie map "summarize every ADR" --agent --daemon     # durable map-reduce over many docs
```

`investigate` runs a Rust-native tool-calling agent across wiki pages (30-120s). `map` transforms many documents with Resonate-backed durable execution (60-300s).
