Global flags on every command: `--json` (structured reads), `--plain` (flat tables), `--no-color`, `-q/-d`, `--dry-run`, `--no-input`, `--config`, `--robot-snapshot/--robot-status/--robot-capabilities`.

## MCP clusters (the 40-tool surface)

25 resources ride along. 38 tools are frozen AM-Rust parity; 2 are toron additives (`release_file_reservations_by_reason`, `list_file_reservations`), and the emitted catalog covers the 38 frozen names only. The same mail, reservation, contact, job, and channel ops exist over MCP for harnesses without a shell; the frozen names are cataloged by `toron catalog --json`. Prefer the CLI whenever a shell exists, and read the tool schema before the first MCP call. Do not copy the foreign 44-tool surface.

| Cluster | Tools |
|---|---|
| Identity (10) | `health_check`, `ensure_project`, `register_agent`, `create_agent_identity`, `whois`, `resolve_pane_identity`, `cleanup_pane_identities`, `list_agents`, `install_precommit_guard`, `uninstall_precommit_guard` |
| Messaging (7) | `send_message`, `reply_message`, `fetch_inbox`, `acknowledge_message`, `mark_message_read`, `search_messages`, `summarize_thread` |
| Reservations (7) | `check_file_reservation_conflicts`, `file_reservation_paths`, `renew_file_reservations`, `release_file_reservations`, `force_release_file_reservation`, `release_file_reservations_by_reason`, `list_file_reservations` |
| Product-bus (5) | `ensure_product`, `products_link`, `search_messages_product`, `fetch_inbox_product`, `summarize_thread_product` |
| Macros (4) | `macro_start_session` (ensure_project + register + reserve + inbox snapshot), `macro_prepare_thread` (registration + thread summary + recent inbox), `macro_contact_handshake` (request + auto-accept + welcome), `macro_file_reservation_cycle` (reserve, optionally release at end) |
| Contacts (4) | `request_contact`, `respond_contact`, `list_contacts`, `set_contact_policy` |
| Build slots (3) | `acquire_build_slot`, `renew_build_slot`, `release_build_slot` |

Onboarding sequence: `ensure_project` -> `register_agent` (upsert) -> `file_reservation_paths` (if editing), or one `macro_start_session`. Pane identity helpers: `resolve_pane_identity` maps a herdr `pane_id` to the agent name; `cleanup_pane_identities` prunes identities whose panes are gone. Send receipts carry the rumor id, which is the same id ack and summarize take.
