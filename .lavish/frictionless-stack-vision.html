The product

One session. Two questions. Then silence until SIGNOFF.

Topology (swarm / loop / open) is how work is supervised. Workflow / stage / compose token is what runs. Those are orthogonal. Today decide collapses them into one keyword, and the TTY briefing that would ask crew N is skipped by every harness --json path.

  1. 0 → Arrive

    Register pin if missing. flywheel helm + snapshot + presence publish + doorbell attach. If a fleet is live: join, do not spawn.

  2. 1 → Brief

    flywheel briefing "<objective>" --json returns ranked proposal: workflow, token, stages, add/remove vs inferred, topology, crew map with default, join-vs-spawn, argv.

  3. 2 → Two questions (one screen)

    Mode: swarm / loop / open (default from proposal). Crew: editable role→N (default from proposal, never from raw @role occurrence count). Add/remove listed as deltas.

  4. 3 → Commit

    flywheel briefing --commit runs argv with explicit --crew, binds role pins, joins steer channel, starts dispatcher, declares coalition intent + reservations, mints corr.

  5. 4 → Supervise without a person

    Doorbell tick is the captain-as-protocol. Benign wakes spend zero tokens. OPEN DECISIONS is the only human interrupt. Rot / write-liveness / nudge budget / WaitCorr wedge keep the fleet from going deaf. SIGNOFF or legal close ends it.

  6. 5 → Second harness

    Same arrive. Briefing sees live pins/lanes/reservations. Default is join: declare intent, reserve, post one kind-9 line, arm watch. Coalition detect/auto-coalesce if files overlap. Never a second wave-swarm.

Quality is already encoded.

Playbook lint, VERIFY fence, P≤2 principles, ce-review residual gate, fail-closed close. The leak is crews executing --raw and skipping the briefing. Fix the door, do not rewrite the gates.

Root causes

Five failures, not fifty symptoms

F1

Decide is a first-match keyword table

One primitive, one argv, no alternatives, no topology, no crew, no join. "feature" in the sentence beats multi-lane. "swarm with 2 crews" falls through to steer. JSON shape is {primitive, reason, argv}. File: flywheel/src/decide.rs.

F2

Crew N is occurrence-count, and robots cannot edit it

crew: auto counts every @planner step as another planner. Gate+dispatch ⇒ 2 planners. TTY steer_brief lets you type a new N, then throws the edit away (test name is the contract). --json skips the prompt. Compose has no --crew, only --allow-crew-expand which confirms the balloon. There is no path from “I want 2” to spawn 2.

F3

Topology is not a decide axis

ADR-0005: /open /loop /swarm are supervision topologies. Skills say this. Decide does not ask. AGENTS.md mixes "use wave-swarm" with "use loop-mode" as if they were workflows. A typo-fix and a 12-bead wave both fall to steer.

F4

Join is a ritual, not a primitive

Coalition form/intent/detect/auto-coalesce, open-mode bootstrap, --reuse, presence, reservations — all exist. Session start never runs them. Helm does not say "fleet live, join this". Presence is empty so discovery fails. Second grok pane starts a parallel universe.

F5

The captain is a person who forgets. Supervision is optional infrastructure.

ADR-0010 already designed doorbell-with-inbox, AFK digest, OPEN DECISIONS, write-liveness, Unknown-never-promoted. ADR-0029 (proposed today) adds rot scoring because panes still die silently. On toron right now: no dispatcher, snapshot mail/reservations degraded, helm reports calm. WaitCorr parks until a receipt that never comes. OBSERVE escalates to a pin that is not watching. You force-check progress because nothing is required to ring you.

Harness rule: print proposal + add/remove, ask the two questions (defaults shown), then briefing --commit --topology … --crew …. No third question. Never-block-on-the-human: if --yes, commit defaults.
